### 2.2 图像处理类（task-2）

| 名词 | 通俗解释 |
|---|---|
| **像素 (Pixel)** | 图像的最小单位，一个小色块。图片 1920×1080 就是横 1920 竖 1080 个色块。 |
| **通道 (Channel)** | 每个像素的颜色由几个数字描述。RGB 就是红、绿、蓝三个通道。 |
| **BGR vs RGB** | ⚠️ **OpenCV 读图的通道顺序是 BGR，Pillow 和 matplotlib 是 RGB**。混用会导致"红蓝颠倒"，这是新手第一大坑。 |
| **灰度图** | 只要一个通道（亮度），从黑到白 0~255。 |
| **分辨率** | 图像的像素总数，越大越清晰、文件越大、算得越慢。 |
| **几何变换** | 缩放（resize）、旋转（rotate）、平移（translate）、翻转（flip）——把图像"变形"的操作。 |
| **插值** | 缩放图像时怎么"猜"新像素的值。最近邻、双线性、双三次是常用方法。 |
| **二值化 / 阈值** | 把灰度图变成非黑即白：大于 127 的变白，小于的变黑。用于把目标从背景里"抠"出来。 |
| **边缘检测 (Canny)** | 找出图像中亮度突变的地方（物体轮廓）。突变 = 边缘。 |
| **轮廓 (Contour)** | 连成一条闭合曲线的边缘点集合，可以理解成"物体的外框"。 |
| **轮廓面积/周长** | 用像素数衡量的物体大小。OpenCV 有 `contourArea()`、`arcLength()` 直接算。 |
| **形态学操作** | 腐蚀（变瘦）、膨胀（变胖）、开闭运算。用来去掉噪点、连接断裂的轮廓。 |
| **视频帧 (Frame)** | 视频就是一秒放几十张图，每张图叫一帧。处理视频 = 逐帧处理图像。 |
| **FPS** | 每秒帧数。30 FPS 就是每秒 30 张。也用来衡量模型推理速度。 |
| **背景减除** | 视频里"动的东西" = 当前帧 − 背景。前提是先建一个"背景模型"。 |
| **MOG2** | 混合高斯模型 v2，OpenCV 里最常用的背景建模算法。它假设每个像素的颜色长期来看符合高斯分布。 |
| **前景 / 背景** | 前景 = 你关心的运动物体；背景 = 不动的场景。 |
| **目标追踪 (Tracking)** | 视频里跟住某个目标，每帧输出它的位置框。task-2 第 5 题就是这个。 |
| **追踪器 (Tracker)** | 具体的追踪算法。OpenCV 提供 CSRT（准但慢）、KCF（快但一般）、MOSSE（最快最糙）。 |
| **边界框 (Bounding Box)** | 圈出目标的矩形框，通常写成 `(x, y, w, h)` 或 `(x1, y1, x2, y2)`。 |
| **IoU（交并比）** | 两个框的重叠程度 = 交集面积 ÷ 并集面积。1 表示完全重合。用来判断"追丢了没"。 |
| **卡尔曼滤波** | 一种"预测 + 修正"的数学方法。根据目标上一帧的运动趋势预测下一帧位置，遮挡时特别有用。 |

### 2.3 深度学习基础（task-3）

#### 网络结构

| 名词 | 通俗解释 |
|---|---|
| **神经元 / 感知机** | 神经网络的最小单位：接收几个输入 → 加权求和 → 过一个激活函数 → 输出。 |
| **权重 (Weight)** | 每个输入的"重要程度"。训练就是不断调整权重，让输出越来越对。 |
| **偏置 (Bias)** | 加在加权和上的常数，让神经元的激活阈值可以移动。没有它，输入全 0 时输出必然为 0，太死板。 |
| **激活函数** | 给网络加入"非线性"的函数。没有它，再多层网络也只等价于一层。常用 **ReLU**（负数变 0，正数不变）。 |
| **全连接层 (FC / Linear)** | 每个输入都连到每个输出，最基础的层。`nn.Linear(784, 128)` 表示 784 个输入接 128 个输出。 |
| **隐藏层** | 输入层和输出层之间的层，负责提取中间特征。 |
| **MLP（多层感知机）** | 就是"全连接层堆几层"的神经网络。task-3 的主角，结构最简单。 |
| **前向传播** | 数据从输入层一路算到输出层，得到预测结果的过程。 |
| **反向传播** | 从输出层的误差往回推，算出每个权重"该负多少责任"（梯度）。 |
| **链式法则** | 反向传播的数学基础：复合函数的导数 = 各层导数相乘。微积分里的内容。 |
| **张量 (Tensor)** | 多维数组。标量是 0 维、向量是 1 维、矩阵是 2 维、图像是 3 维。PyTorch 里一切都是张量。 |
| **自动求导 (Autograd)** | PyTorch 的"外挂"：你只管写前向传播，它自动帮你算所有梯度。task-3 第 2 题就靠它。 |
| **CUDA** | NVIDIA 显卡的并行计算平台。PyTorch 靠它把计算搬上 GPU。 |

#### 训练过程

| 名词 | 通俗解释 |
|---|---|
| **损失函数 (Loss)** | 衡量"预测和正确答案差多少"的分数。训练目标就是让它越来越小。 |
| **MSE（均方误差）** | 最常用的回归损失：(预测−真实)² 的平均。task-3 第 2 题用它。 |
| **交叉熵 (CrossEntropy)** | 最常用的分类损失。MNIST 十分类就用它。 |
| **梯度下降** | 优化算法：沿着损失下降最快的方向（梯度的反方向）走一小步，反复走，直到谷底。 |
| **学习率 (LR)** | 每一步走多大。太大容易"跨过"最低点（震荡不收敛），太小则慢到天荒地老。最关键的参数。 |
| **优化器 (Optimizer)** | 梯度下降的改良版。**SGD**（基础）、**Adam**（自适应，新手首选，收敛快）。 |
| **Epoch** | 把整个训练集完整看一遍。训练 10 个 epoch = 数据被过了 10 遍。 |
| **Batch（批）** | 一次喂给模型的样本数。60000 张图分 64 张一批，就是 938 个 batch。 |
| **Iteration（迭代）** | 处理一个 batch 算一次迭代。1 epoch = 938 iteration。 |
| **Batch Size** | 一个 batch 多大。越大越稳但越吃显存，常见 32/64/128。 |
| **混合精度训练** | 用 float16（半精度）代替 float32 做计算，速度快一倍、显存省一半，精度几乎不损失。 |
| **梯度清零** | ⚠️ PyTorch 的梯度会累加，每个 batch 前必须 `optimizer.zero_grad()`，否则训练全乱。新手必踩。 |

#### 模型效果

| 名词 | 通俗解释 |
|---|---|
| **过拟合** | 模型把训练集"背下来"了。训练准确率 99%，测试只有 70% —— 换新题就不会做。 |
| **欠拟合** | 模型太笨。训练集都学不会，准确率上不去。 |
| **正则化 (L1/L2)** | 惩罚过大的权重，防止模型死记硬背。L2 就是给损失加一项 λ·Σw²。 |
| **Dropout** | 训练时随机"关掉"一部分神经元，逼网络不依赖某几个特定神经元。防过拟合神器。 |
| **批归一化 (BatchNorm)** | 每层输入先标准化（均值 0、方差 1），让训练更稳、更快。 |
| **训练集 / 验证集 / 测试集** | 训练集用来学；验证集用来调参（每轮看效果）；测试集只在最后用一次，检验真实水平。 |
| **准确率 (Accuracy)** | 预测对的比例，分类任务最直观的指标。 |
| **混淆矩阵** | 一张表，第 i 行第 j 列 = "真实是 i 类、被预测成 j 类"的样本数。能看出模型把哪些类搞混了。 |
| **决定系数 R²** | 回归任务指标，衡量拟合有多好。**=1 完美，=0 相当于只会猜平均值**。task-3 第 2 题要输出它。 |
| **最小二乘法** | 经典拟合方法：找一组参数让"误差平方和"最小。梯度下降是求它的现代做法。 |

### 2.4 进阶模型（task-4）

| 名词 | 通俗解释 |
|---|---|
| **卷积 (Convolution)** | 拿一个小窗口（卷积核）在图像上滑动，每滑一处做加权求和。能提取边缘、纹理等局部特征。 |
| **卷积核 / 滤波器** | 那个小窗口，比如 3×3 的矩阵。核里的数值就是"要学什么特征"，也是训练出来的。 |
| **CNN（卷积神经网络）** | 用卷积层堆起来的网络，处理图像的标准架构。比 MLP 参数少得多、效果好得多。 |
| **池化 (Pooling)** | 把特征图"缩小"（比如 2×2 里取最大值），减少计算量，增加抗干扰能力。 |
| **特征图 (Feature Map)** | 卷积层的输出，每一张表示某种特征在图像各位置的强弱。 |
| **注意力机制 (Attention)** | 让模型"重点看"某些部分。"这张图里球在哪？先看亮色区域"——这就是注意力。 |
| **Transformer** | 完全基于注意力机制的架构。原本做 NLP，图像领域也大杀四方。 |
| **ViT** | Vision Transformer，把图片切成小方块当"单词"喂给 Transformer。 |
| **目标检测 (Object Detection)** | 不仅要知道图里有啥，还要框出在哪。分类 + 定位。 |
| **YOLO** | "You Only Look Once"，一次就出检测结果，速度极快，工业界最流行。 |
| **mAP** | 目标检测的核心指标，综合了各类别的精度和召回率，越高越好。 |
| **预训练权重** | 别人在大数据集上训好的模型参数。你在它基础上微调，比从零训练省几十倍算力。 |
| **迁移学习** | 用预训练模型解决自己的任务。task-4 给的 `drone.pt` 就是这种思路。 |
| **Epoch / 训练轮次**（YOLO 语境） | YOLO 训练输出里会出现 loss 曲线、mAP 曲线，含义同 task-3。 |
| **模型量化** | 把参数从 float32 换成 float16 或 int8，模型变小、推理变快，精度略降。 |
| **fp16 / int8** | 16 位浮点 / 8 位整数。位数越少越省资源。 |
| **ONNX** | 一个"通用模型格式"，让 PyTorch 训的模型能在各种平台/框架上跑。 |
| **TensorRT** | NVIDIA 的推理加速引擎，能把模型在 N 卡上跑得更快。 |
| **GAN（生成对抗网络）** | 两个网络互相对抗：生成器造假图，判别器辨真假，越练都越强。 |
| **生成器 / 判别器** | GAN 的两个主角。生成器负责"造"，判别器负责"鉴"。 |
| **U-Net** | 形状像"U"的网络：先下采样压缩，再上采样还原。做图像到图像的转换（去雾、分割）。 |
| **pix2pix** | 一种图像翻译 GAN，"输入一张图 → 输出另一张图"，去雾用它很合适。 |
| **算法架构（task-4 提供）** | README 里给的代码是 pix2pix 的生成器（U-Net）+ 判别器（PatchGAN），理解结构比抄代码重要。 |
| **PSNR（峰值信噪比）** | 图像质量指标，衡量"修复图和原图有多像"，越高越好，单位 dB。task-4 第 4 题要算。 |
| **RNN（循环神经网络）** | 有"记忆"的网络，能处理序列数据（时间序列、文本）。 |
| **LSTM / GRU** | RNN 的改良版，解决了长序列遗忘问题。LSTM 更复杂，GRU 更轻量。 |
| **TCN（时间卷积网络）** | 用卷积处理时序数据，并行快、感受野大。 |
| **时序预测** | 根据历史数据预测未来（明天多少度、下月销多少）。 |
| **MAE / MSE / RMSE** | 回归任务的三大评价指标：平均绝对误差 / 均方误差 / 均方根误差。越小越好。 |

## 3. 四周学习路线

|---|---|

### 第 2 周：图像处理 + 完成 task-2

**目标**：理解"图像就是数字矩阵"，能用 OpenCV 做基本操作。

| 天 | 内容 |

⚠️ **task-2 第 5 题的思考题**："如何提高追踪准确度？"——提示：换更强的追踪器？目标丢失后重新检测（检测+追踪结合）？预处理去噪？多尺度搜索？**写出你的实验对比，比结论对错更重要。**

### 第 3 周：深度学习基础 + 完成 task-3

**目标**：理解神经网络怎么"学"，跑通 MNIST 训练。

| 天 | 内容 |
|---|---|

| 3 | PyTorch 基础：Tensor、autograd、nn.Module |
| 4 | 题 2：梯度下降拟合那个二元函数（理解参数怎么被"学"出来） |
| 5-6 | 题 3：搭 MLP、训练 MNIST、画 Loss/Acc 曲线 |
| 7 | 可视化预测结果、写文档、调参对比（改学习率/层数看效果） |

⚠️ **task-3 第 2 题的真实参数**是：`a1=2, a2=1.5, a3=3, a4=0.5, a5=-0.5, a6=0.8, b=2026`。训练完看看你拟合出来的参数离这些值有多近，R² 越接近 1 越好。

### 第 4 周：task-4（大一任选 1 个方向）

| 方向 | 难度 | 适合谁 | 提示 |
|---|---|---|---|
| **1. YOLO 目标检测** | ★★★★☆ | 想做应用、不怕配环境 | 有现成权重，主要是训练+量化导出 |

## 5. 避坑清单

> 这些都是新手一定会踩的坑，提前知道能省下大量时间。

### 环境类

| 问题 | 原因 | 解决 |
|---|---|---|
| `conda` 不是内部命令 | 没重开终端 | 关掉终端重新打开 |
| `import cv2` 报错 | 用错 Python 了 | 确认 `conda activate conmsen` 后再运行 |
| Python 版本不对 | 系统有多个 Python | 用 `where python` 检查第一个是不是 `D:\miniconda3\envs\conmsen` |
| `pip install` 很慢 | 没走镜像 | 已配好清华源，若失效加 `-i https://pypi.tuna.tsinghua.edu.cn/simple` |

### 图像类

| 问题 | 原因 | 解决 |
|---|---|---|
| 图片红蓝颠倒 | **OpenCV 是 BGR，matplotlib 是 RGB** | 显示前 `cv2.cvtColor(img, cv2.COLOR_BGR2RGB)` |
| `cv2.imread` 返回 `None` | 路径错/中文路径 | 用绝对路径；Windows 中文路径改用 `cv2.imdecode(np.fromfile(path, np.uint8), -1)` |
| matplotlib 中文变方框 | 字体未设置 | 加 `plt.rcParams['font.sans-serif'] = ['SimHei']` 和 `plt.rcParams['axes.unicode_minus'] = False` |
| 视频保存后打不开 | 编码器/尺寸不匹配 | 用 `cv2.VideoWriter_fourcc(*'mp4v')`，尺寸必须和读取的一致 |

### 训练类

| 问题 | 原因 | 解决 |
|---|---|---|
| Loss 不下降 | 学习率太大/太小 | 先用 Adam + lr=0.001 试；画 Loss 曲线看是震荡（太大）还是不动（太小） |
| Loss 变成 `nan` | 学习率过大或数据没归一化 | 数据除以 255 归一化到 [0,1]；减小学习率 |
| 训练准确率 99%，测试 50% | 过拟合 | 加 Dropout、减小模型、早停 |
| 显存不足 (CUDA out of memory) | batch size 太大 | 调小 batch size（如 64 → 32） |
| 梯度不更新 | 忘了 `zero_grad()` | 每轮循环开头加 `optimizer.zero_grad()` |
| 训练特别慢 | 没用 GPU | 检查 `torch.cuda.is_available()`，模型和数据都要 `.to('cuda')` |

### 心态类

| 坑 | 真相 |
|---|---|
| "我数学不好，学不了" | 大一的知识够用。遇到不懂的数学，查 3Blue1Brown 建立直觉即可。 |
| "网上找不到答案，我是不是太笨" | 搜报错信息的关键词，99% 的坑别人踩过。 |
| "我要先把原理全搞懂再动手" | ❌ 学深度学习必须**边跑边学**。先跑通，再问为什么。 |

### 找轮廓 + 算面积周长（task-2 题 3）

```python
import cv2

img = cv2.imread('example1.jpg')
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)     # 转灰度
_, thresh = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)  # 二值化

contours, _ = cv2.findContours(thresh, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)

total_area = sum(cv2.contourArea(c) for c in contours)   # 总面积
total_perimeter = sum(cv2.arcLength(c, True) for c in contours)  # 总周长
print(f'总面积: {total_area}, 总周长: {total_perimeter}')

cv2.drawContours(img, contours, -1, (0, 255, 0), 2)  # 画出来（绿色，线宽2）
cv2.imwrite('contours_result.jpg', img)
```

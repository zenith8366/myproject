## 0. 开始前：命令、地图、三条铁律

### 0.1 每天要用的命令

**方式一：一键脚本（日常用这个）** —— 工程里备了两个等价脚本，任选其一：

| 脚本 | 怎么运行 |
|------|----------|
| `example/build.bat` | 在资源管理器里**双击**；或在任意 cmd 窗口里运行 `E:\myproject\stm32s\Comsen_recruitment_hardware-1.0.0\example\build.bat` |
| `example/build.sh` | bash 终端里：`cd /e/myproject/stm32s/Comsen_recruitment_hardware-1.0.0/example && ./build.sh` |

两个脚本做的事一样：自动把 cmake/ninja 加进 PATH（不用手动 export）→ 首次运行自动配置工程 → 增量编译 → 末尾打印固件路径和 FLASH/RAM 占用。编译出错会停下并显示错误原文（bat 版带 pause，双击运行也能看清错误）。

**方式二：手动敲命令（想理解构建在干什么，或脚本出问题时用）**

在仓库根目录（`E:\myproject\stm32s\Comsen_recruitment_hardware-1.0.0`）的 bash 终端里：

```bash

# 构建。日常只跑第二行；改过 CMakeLists.txt 或新建了 .c 文件后，要跑第一行重新配置
```

> 两种方式完全等价：脚本内部就是这两条 cmake 命令（cmake/ninja 的目录路径写死为上面的 bundle 地址）。


### 0.2 工程地图（先记住这四样）

| 位置 | 作用 |
|------|------|
| `example/Core/Src/main.c` | 骨架：初始化外设 → 建 5 个 FreeRTOS 任务 → 启动调度器。"USER CODE" 注释之间的区域才是给你改的 |
| `example/Core/Inc/*.h` | 所有库的接口（函数原型）。**看接口只看这里** |
| `example/lib/*.a` | 6 个预编译静态库（黑盒，源码不可见）。要替换哪个，就从 CMakeLists 删哪个 |
| `example/CMakeLists.txt` | 告诉编译器"用哪些源文件、链接哪些库"。第 66-76 行是库的链接列表 |
| `example/User/` | **你的家**（D2 起新建）：`calculator_app.c`（替换示例应用库）、`touch_filter.c`（替换滤波库）、`calculator_engine.c`（替换引擎库）——每个文件都实现同名库头文件里的接口，**同名同签名** |

5 个任务（由 main.c 创建，任务体最终都进入你的 `calculator_app.c`）：

| 任务 | 优先级 | 栈 | 在你的方案里的分工 |
|------|--------|-----|------|
| KeyTask | 高 | 512 B | 每 10ms 读触摸芯片 → 去抖 → 投递按键事件 |
| defaultTask | 中 | 512 B | 心跳：闪 PC13 的 LED |
| controllerTask | 中 | 1024 B | 汇聚串口数据 + 按键事件 → 更新输入/显示 |
| lcdTask | 中低 | 768 B | **全工程唯一碰 LCD 的任务** |
| calculatorTask | 低 | 2048 B | 目前空转（大栈留给进阶功能） |

### 0.3 三条铁律（违反了必花屏/必卡死/白调半天）

1. **LCD 的行参数是定长 16 字符**。传"恰好 16 个字符"的字符串字面量，或手动填满 16 字节。少传了 C 编译器不报错，屏幕会花给你看。
2. **替换某模块 = 删对应 `.a` + 加自己的 `.c`，两者不共存**（README 规则）。而且你的 `.c` 要和原库**同名同签名**——对着该模块的头文件写（全文清单见《函数清单.md》§3），这样调用方一行都不用改。共存时链接结果难以预期：函数名只要写错或漏写一个，旧库就会悄悄替你"补位"。删干净再构建。
3. **USB 接收回调里只做"拷贝 + 置标志"**：不能 `osDelay`、不能刷屏、不能调 FreeRTOS API。重活留给任务。

### 1.1 学（约 40 分钟）

打开 `example/Core/Src/main.c`，对照下面这张"读码地图"通读一遍：

| 行号 | 内容 | 你要理解的一句话 |
|------|------|------------------|
| 50 | `TIM_HandleTypeDef htim3;` | 全局计时器句柄，LCD/触摸库靠它计时（改名会链接失败） |
| 139-171 | `main()` 上半段 | HAL → 时钟 → GPIO → TIM3 → **启动 TIM3**：外设初始化顺序 |
| 176 | `osKernelInitialize()` | 初始化 RTOS 内核 |
| 191 | `calculator_app_init()` | 调度器启动前的应用初始化（D2 之后这里进你的代码） |
| 196-208 | `osThreadNew(...)` ×5 | 创建 5 个任务（每个任务有独立栈） |
| 219 | `osKernelStart()` | 启动调度器：之后 5 个任务开始"并发"跑，这句话之后的代码永不执行 |
| 389-456 | 5 个任务函数 | 每个函数体只是 `(void)argument; calculator_xxx_task();`——**转发到库**。D2 起你自己的版本将接管它们 |
| 466-477 | `HAL_TIM_PeriodElapsedCallback` | TIM4 中断每秒给 HAL 数 1000 次（`HAL_Delay` 的时基） |

**FreeRTOS 小课堂（概念 1、2）**：
- **任务 = 死循环函数**（`for(;;)` 永不返回），RTOS 在它们之间切换。
- **优先级**：数字大的先跑；高优先级就绪时立刻抢占低优先级。`osPriorityHigh` 的 KeyTask 永远最先响应。

## Day 2 · 换脑手术：自己的应用接管（+ 顺势点亮 USB）

**今日目标**：删掉 `libcalculator_app.a`，让 `example/User/calculator_app.c`（你写的**同名实现**）接管全板；顺利的话电脑能识别出 COM 口。

### 2.1 学（约 30 分钟）

**FreeRTOS 小课堂（概念 3、4、8）**：
- `osDelay(ms)`：**阻塞式**延时——延时期间让出 CPU，别的任务继续跑。任务里延时用它。
- `HAL_Delay(ms)`：**忙等**——死循环烧 CPU。高优先级任务里用它会把低优先级任务全部饿死。
- **静态分配**：本工程所有任务/队列的内存都是开机就申请好的（heap 只有 1024 字节）。你的共享变量也放全局（`static`），别塞在任务栈里。

### 2.2 改（三件事）

#### ① 新建 `example/User/calculator_app.c`（替换示例应用库）

为什么叫这个名字：它实现的是 `calculator_app.h` 里声明的那 6 个函数——**文件名和函数名都与原库同名同签名**，这正是 README 说的"同名实现"。整份文件如下——**标 `TODO(你写)` 的地方请自己补**，其余照抄。这是你这周的核心文件。

```c
/* ============================================================================
 * calculator_app.c —— 你自己的应用层（替换 lib/libcalculator_app.a，同名同签名）
 *
 * 【契约】main.c 只会调用 calculator_app.h 里声明的这 6 个函数：
 *     calculator_app_init()         在调度器启动之前被调用
 *     calculator_heartbeat_task()   心跳（用来闪 PC13 的 LED）
 *     calculator_key_task()         读触摸按键
 *     calculator_lcd_task()         刷新 LCD（唯一允许碰 LCD 的任务）
 *     calculator_controller_task()  控制逻辑（按键、串口数据的汇合处）
 *     calculator_compute_task()     重计算（栈最大 2048 B）
 *   少写一个，链接就会报 undefined reference to `calculator_xxx_task'。
 *
 * 【纪律】除了这 6 个函数，本文件其它函数/变量全部 static，
 *         避免将来和静态库里的符号撞名。
 * ========================================================================== */

#include "calculator_app.h"   /* 保证与 main.c 看到的函数签名完全一致 */
#include "main.h"             /* HAL_GPIO_TogglePin / GPIOC / GPIO_PIN_13 */
#include "cmsis_os.h"         /* osDelay、栈高水位查询等（FreeRTOS 的封装） */
#include "lcd1602.h"          /* 显示库接口 */

/* ------------------------------- 可调参数 -------------------------------- */
#define APP_KEY_PERIOD_MS    10U    /* 触摸扫描周期：库约定 10ms 一次 */
#define APP_CTRL_PERIOD_MS   10U    /* 控制任务周期 */
#define APP_LCD_PERIOD_MS   100U    /* 刷新周期：LCD 库内部用 HAL_Delay 逐字节写，别设太小 */
#define APP_HB_PERIOD_MS    500U    /* 心跳灯：每 500ms 翻转一次 = 每秒闪 1 下 */

/* -------------------------------- 共享状态 ------------------------------- */
/* 【FreeRTOS 学习点】5 个任务共享一份数据，规则只有两条：
 *   1) 每个字段只有一个"写者"任务；
 *   2) 读快照时用 app_lock()/app_unlock() 包住"拷贝那几个字节"的一瞬间，
 *      临界区里绝不做慢操作（LCD、延时、串口都是慢操作）。       */
typedef struct
{
  char             line1[16];   /* LCD 快照第 1 行：定长 16，不含结束符 */
  char             line2[16];   /* LCD 快照第 2 行 */
  volatile uint8_t dirty;       /* 有新内容置 1，lcdTask 显示完清 0 */

  uint8_t          key_fifo[16];/* 按键事件队列：keyTask 写、controllerTask 读 */
  volatile uint8_t key_head;
  volatile uint8_t key_tail;
} app_state_t;

static app_state_t s_app;       /* 放全局 .bss 区，不要放任务栈上！ */

/* -------------------------------- 小工具 --------------------------------- */

/* 超短临界区的开启/恢复：关中断 → 干那一两微秒的活 → 恢复原状态。
 * 【为什么不用 taskENTER_CRITICAL】那个 API 只有调度器启动之后才能正常配对；
 * 本文件的 app_display 在"调度器启动前"（calculator_app_init 里）也会被调用，
 * 所以用 PRIMASK 保存/恢复这招——不挑时机，而且和 usbd_cdc_if.c 里
 * CDC_TakeExportRequest_FS 的写法完全一致。 */
static uint32_t app_lock(void)
{
  uint32_t primask = __get_PRIMASK();
  __disable_irq();
  return primask;
}

static void app_unlock(uint32_t primask)
{
  if (primask == 0U)
  {
    __enable_irq();
  }
}

/* 数一串字符的长度，最多数到 16（不想依赖 strlen 就这么写） */
static uint8_t app_len16(const char *s)
{
  uint8_t n = 0U;
  while (n < 16U && s[n] != '\0')
  {
    n++;
  }
  return n;
}

/* 把字符串填成"恰好 16 字符"：不足补空格。
 * 【铁律 1】lcd1602_write_lines 的两行形参必须真的指向 16 字节，
 *           短了会读越界 → 屏幕花屏。 */
static void app_fill16(char out[16], const char *s)
{
  uint8_t len = app_len16(s);
  for (uint8_t i = 0U; i < 16U; i++)
  {
    /* TODO(你写)：i 小于 len 时装 s[i]，否则装 ' '（提示：一个三目运算符） */
    out[i] = ' ';
  }
}

/* 更新"显示快照"。跨任务写共享数据的标准姿势，照抄即可。 */
static void app_display(const char *l1, const char *l2)
{
  char     t1[16], t2[16];
  uint32_t pm;

  app_fill16(t1, l1);
  app_fill16(t2, l2);

  pm = app_lock();
  for (uint8_t i = 0U; i < 16U; i++)
  {
    s_app.line1[i] = t1[i];
    s_app.line2[i] = t2[i];
  }
  s_app.dirty = 1U;
  app_unlock(pm);
}

/* ============================== 6 个契约函数 ============================== */

/* 在调度器启动之前被调用：只能做"初始化和硬件自检"，不能用 osDelay！ */
void calculator_app_init(void)
{
  lcd1602_init();                          /* LCD 初始化（内部用 HAL_Delay，没问题） */
  app_display("Comsen Calc", "my app v1"); /* TODO(你写)：改成你自己的欢迎语 */
}

/* 心跳任务：证明调度器活着、你的程序没被玩死 */
void calculator_heartbeat_task(void)
{
  for (;;)
  {
    HAL_GPIO_TogglePin(GPIOC, GPIO_PIN_13);
    osDelay(APP_HB_PERIOD_MS);             /* 阻塞式延时：延时期间让出 CPU */
  }
}

/* 按键任务：D4 再填内容，现在先空转 */
void calculator_key_task(void)
{
  for (;;)
  {
    /* TODO(D4)：读键 → 去抖 → 投递事件 */
    osDelay(APP_KEY_PERIOD_MS);
  }
}

/* 显示任务：全工程唯一允许调用 lcd1602_* 的任务（所以它不需要抢锁） */
void calculator_lcd_task(void)
{
  char l1[16], l2[16];

  for (;;)
  {
    if (s_app.dirty != 0U)
    {
      /* 用最短的临界区把快照拷出来 */
      uint32_t pm = app_lock();
      for (uint8_t i = 0U; i < 16U; i++)
      {
        l1[i] = s_app.line1[i];
        l2[i] = s_app.line2[i];
      }
```

**FreeRTOS 小课堂（概念 6、7）**：
- **ISR（中断上下文）规则**：中断里不能阻塞、不能调非 `FromISR` 的 RTOS API。所以回调里**只做拷贝**，数据放环形缓冲，任务侧再来取。

```c
/* ===== D3：供任务侧取走数据（短临界区，照抄 TakeExport 的姿势） ===== */
uint16_t CDC_RxTake(uint8_t *dst, uint16_t max_len)
{
  uint32_t primask = __get_PRIMASK();
  uint16_t n = 0U;

  __disable_irq();
  while ((s_rx_tail != s_rx_head) && (n < max_len))
  {
    dst[n++] = s_rx_ring[s_rx_tail];
    s_rx_tail = (uint16_t)((s_rx_tail + 1U) % CDC_RX_RING_SIZE);
  }
  if (primask == 0U)
  {
    __enable_irq();
  }
  return n;
}

uint8_t CDC_RxOverflow(void)
{
  uint8_t v = s_rx_overflow;
  s_rx_overflow = 0U;
  return v;
}
```

```c
{
  USBD_CDC_HandleTypeDef *hcdc;

  if (hUsbDeviceFS.dev_state != USBD_STATE_CONFIGURED)
  {
    return;                              /* 电脑还没把这个设备准备就绪，别发 */
  }

  {

  for (uint8_t t = 0U; (t < 50U) && (hcdc != NULL) && (hcdc->TxState != 0U); t++)

    osDelay(1U);

  for (uint16_t i = 0U; i < len; i++)
  {
    s_tx_buf[i] = data[i];
  }

  /* 发送；忙就等 1ms 重试（最多 50 次） */
  for (uint8_t t = 0U; t < 50U; t++)
  {
    if (CDC_Transmit_FS(s_tx_buf, len) != USBD_BUSY)
    {
      return;
    }
    osDelay(1U);
  }
  /* 一直忙：通常出现在拔线之后。插回 USB 即恢复正常。 */
```

```c
static void app_key_push(uint8_t ev)
{
  uint8_t next = (uint8_t)((s_app.key_head + 1U) & 0x0FU);

  if (next == s_app.key_tail)
  {
    return;                      /* 队满：丢事件（正常操作不会满） */
  }
  s_app.key_fifo[s_app.key_head] = ev;
  s_app.key_head = next;

{
  if (s_app.key_head == s_app.key_tail)
  {
    return 0U;                   /* 队空 */
  }
  *ev = s_app.key_fifo[s_app.key_tail];
  s_app.key_tail = (uint8_t)((s_app.key_tail + 1U) & 0x0FU);
  return 1U;
}
```

```c
 * 例：7 → "7.00"；-2.5 → "-2.50"；超范围/NaN → "Error" */
static void app_format_float(float v, char *out, uint8_t out_size)
{
  char     tmp[16];
  uint8_t  n = 0U;
  uint8_t  j = 0U;
  uint8_t  neg = 0U;
  uint32_t ip;
  uint32_t fp;

  if (!(v > -1.0e9f && v < 1.0e9f))     /* NaN 和无穷也走这里 */
  {
    const char *e = "Error";
    uint8_t k = 0U;
    while (e[k] != '\0' && (uint8_t)(k + 1U) < out_size)
    {
      out[k] = e[k];
      k++;
    }
    out[k] = '\0';
    return;
  }

  if (v < 0.0f)
  {
    neg = 1U;
    v = -v;
  }

  ip = (uint32_t)v;                                   /* 整数部分 */
  fp = (uint32_t)(((v - (float)ip) * 100.0f) + 0.5f); /* 小数部分，四舍五入 */
  if (fp >= 100U)                                     /* 进位：0.999.. → 1.00 */
  {
    ip++;
    fp -= 100U;
  }

  /* 整数部分倒着生成（% 10 取末位） */
  do
  {
    tmp[n++] = (char)('0' + (ip % 10U));
    ip /= 10U;
  } while (ip > 0U && n < 12U);

  if (neg && (j + 1U) < out_size)
  {
    out[j++] = '-';
  }
  while (n > 0U && (j + 1U) < out_size)
  {
    out[j++] = tmp[--n];               /* 反转回来 */
  }
  if ((j + 1U) < out_size) { out[j++] = '.'; }
  if ((j + 1U) < out_size) { out[j++] = (char)('0' + (fp / 10U)); }
  if ((j + 1U) < out_size) { out[j++] = (char)('0' + (fp % 10U)); }
```

## 附录 A · FreeRTOS 小课堂速查

| # | 概念 | 一句话 | 工程里的位置 |
|---|------|--------|--------------|
| 1 | 任务 = 死循环函数 | `for(;;)` 永不返回 | main.c 的 5 个任务函数 |
| 2 | 优先级抢占 | 数字大的先跑，就绪即抢 | main.c 各任务的 `.priority` |
| 3 | `osDelay` 阻塞延时 | 延时期间让出 CPU | 你的每个任务循环 |

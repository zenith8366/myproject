## 图 1 · 文件地图（每样东西是什么）

```text
example/
├── software.ioc                      CubeMX 配置：引脚 / 时钟 / 外设（只读参考）
├── CMakeLists.txt                ★   构建总目录：用哪些源文件、链接哪些库
├── build.sh / build.bat              一键编译脚本（本地新增）：bash 里 ./build.sh，或双击 build.bat
├── CMakePresets.json / cmake/        构建辅助与细节（不用动）
├── startup_stm32f103xb.s             启动汇编：上电后的第一段代码
├── stm32f103c8tx_flash.ld            链接脚本：Flash / RAM 怎么摆
│
├── Core/Src/
│   ├── main.c                    ★   骨架：初始化硬件 → 建 5 个任务 → 启动调度器
│   ├── freertos.c                    RTOS 钩子（内存分配失败 → 复位）
│   ├── stm32f1xx_it.c                中断服务函数（TIM4 时基、USB 中断…）
│   ├── stm32f1xx_hal_timebase_tim.c  HAL 毫秒时基 = TIM4（HAL_Delay 的心脏）
│   └── msp / system / sysmem / syscalls   外设底层与系统杂项
│
├── Core/Inc/
│   ├── main.h · FreeRTOSConfig.h · stm32f1xx_hal_conf.h · stm32f1xx_it.h   配置头文件
│   └── lcd1602.h · ttp229.h · touch_filter.h · touch_model.h ·
│       calculator_engine.h · calculator_app.h   ←── 六个库的"菜单"（只声明）
│
├── USB_DEVICE/
│   ├── App/usb_device.c              MX_USB_DEVICE_Init() 的实现（D2 学会调用它）
│   ├── App/usbd_cdc_if.c / .h    ★   CDC 收 / 发回调 —— D3 加环形缓冲的地方
│   ├── App/usbd_desc.c               USB 描述符（设备名 / 厂商 ID）
│   └── Target/usbd_conf.c            USB 底层配置（静态分配等）
│
├── lib/                              6 个预编译库（"厨房"，看不到源码）
│   ├── libcalculator_app.a           示例应用      → D2 被你替换，删
│   ├── libcalculator_engine.a        表达式引擎    → D6 被你替换，删
│   ├── libtouch_filter.a             按键滤波      → D5 被你替换，删
│   ├── libtouch_model.a              触摸组合模型  → 未使用，删
│   ├── liblcd1602.a                  显示驱动      → 一直用
│   └── libttp229.a                   触摸原始读取  → 一直用
│
├── User/                         ★★  你新建的家（D2 起，三个同名替换文件）
│   ├── calculator_app.c              应用与界面（替换 libcalculator_app.a）
│   ├── touch_filter.c                按键滤波（替换 libtouch_filter.a）
│   └── calculator_engine.c           解析器+求值器（替换 libcalculator_engine.a）
│
├── Drivers/                          ST 官方 HAL / CMSIS（上游，别动）
├── Middlewares/                      FreeRTOS + ST USB 协议栈（上游，别动）
├── build/                            编译产物：software.elf / .hex / .bin / .map
└── （隐藏）.vscode / .settings / .clangd / .gitignore   编辑器与工具配置，与固件无关
```

## 图 2 · 编译与链接：谁进固件，由 CMakeLists 说了算

```text
example/CMakeLists.txt                       ← ★ 你改这里：加源文件 / 删库
  │
  ├─ add_subdirectory(cmake/stm32cubemx)
  │      └─ cmake/stm32cubemx/CMakeLists.txt ：CubeMX 侧全部源文件（约 40 个 .c：
  │          main.c、freertos.c、HAL、FreeRTOS、USB 栈、启动汇编……）一般别动
  │
  ├─ target_sources(…)
  │      └─ ★ D2/D4/D6 起陆续加入 User/ 的三个实现文件
  │
  └─ target_link_libraries(…)
         └─ stm32cubemx + lib/ 下的 6 个 .a（★ 被替换的逐个删掉）

              编译：全部 .c → .obj（main.c.obj、calculator_app.c.obj…… 约 47 个）
              链接：按函数名"配对"（你的 .obj 排在库前面——见手册三条铁律）
                ▼
      build/Debug/software.elf ──objcopy──► .hex / .bin ──烧录──► 板子
```

## 图 3 · 运行时调用关系（main.c ↔ User/ 三文件 ↔ 库）

```text
┌──────────────────── main.c（CubeMX 骨架，基本不动）─────────────────────┐
│ main(): HAL/时钟/GPIO 初始化 → 启动 TIM3 → osKernelInitialize()         │
│         → osThreadNew() ×5 建任务 → osKernelStart() 启动调度器          │
│                                                                        │
│ StartDefaultTask()    { calculator_heartbeat_task();   }  ← 五处"转发" │
│ KeyTaskFunc()         { calculator_key_task();         }    只按函数名  │
│ lcdTaskFunc()         { calculator_lcd_task();         }    办事       │
│ calculatorTaskFunc()  { calculator_compute_task();     }               │
│ controllerTaskFunc()  { calculator_controller_task();  }               │
└──────────────────────────────────┬─────────────────────────────────────┘
                                   │ 链接器按这 6 个名字配对：
                                   │   D2 之前 → libcalculator_app.a
                                   │   D2 之后 → User/calculator_app.c（你写的）
                                   ▼
┌─────────────────── User/（你的大脑：三个同名替换文件）───────────────────┐
│ 契约：calculator_app_init + 5 个 *_task                                 │
│ 模块：touch_filter.c（去抖）· app_calc_input（输入）· calculator_engine.c（求值）│
└──────┬──────────────────┬──────────────────┬────────────────────────────┘
       │ 调用              │ 调用              │ 调用
       ▼                   ▼                   ▼
┌────────────┐     ┌────────────┐     ┌──────────────────────────┐
│liblcd1602.a│     │ libttp229.a│     │ FreeRTOS / HAL（平台层）  │
│   显示      │     │  触摸读取   │     │ osDelay、HAL_Delay、GPIO… │
└────────────┘     └────────────┘     └──────────────────────────┘
```

## 图 4 · 业务数据流（任务 2/3/4 全做完后的完整链路）

```text
【触摸通道】                                    【串口通道】
手指按下                                        电脑打字
  │                                              │
  ▼                                              ▼
ttp229_read_physical() [libttp229.a]        USB 中断 → CDC_Receive_FS()
  │ 30 位位图（每 10ms 读一次）                  │ 只做一件事：拷进 128B 环形缓冲
  ▼                                              ▼
touch_filter_update()（你写：连续判定+单键锁定） CDC_RxTake()（任务侧短临界区取走）
  │ 按下 / 松手事件                              │
  ▼                                              ▼
app_key_push() ──► key_fifo ──► app_key_pop()  app_usb_poll() ──► 回显 app_usb_send()
  │                                              │
  ▼                                              │
s_key_map[键号] → 字符                          │
  └───────────────────┬──────────────────────────┘
                      ▼
              app_calc_input()   输入状态机（数字/运算符/AC/退格/=）
                      │ 改写 s_expr
                      ▼
              app_calc_show() ──app_display()──► 显示快照（line1/line2 + dirty 标志）
                      │                                    ▲
       按 '=' ──► app_calc_evaluate()                      │ 每 100ms 检查 dirty
                      │ calculator_evaluate() 两遍扫描（你的引擎）│
                      │ → app_format_float()               │
                      └─ 结果回填 s_expr ─────────► calculator_lcd_task()
                                                           │
                                                           ▼
                                                 lcd1602_write_lines() [liblcd1602.a]
                                                           ▼
                                                     屏幕（2 行 × 16 字符）
```

> 图中 `app_xxx` 住在 `User/calculator_app.c`；`touch_filter_update` 住在 `User/touch_filter.c`；`calculator_evaluate`/`parse_xxx` 住在 `User/calculator_engine.c`；`[xxx]` 是预编译库；其余文件的作用见图 1。

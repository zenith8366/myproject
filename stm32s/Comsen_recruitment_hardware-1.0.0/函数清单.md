## 1. 提供的库函数（只用不改）

> 声明在 `example/Core/Inc/` 的头文件里；实现在 `example/lib/*.a`（预编译，源码不可见）。
> 想自己查库里有哪些符号：`arm-none-eabi-nm --defined-only example/lib/libXXX.a | grep ' T '`

### 1.1 lcd1602 —— 1602 字符屏显示（liblcd1602.a）

| 函数 | 作用 | 备注 |
|------|------|------|
| `lcd1602_init(void)` | 初始化 LCD（GPIO 时序 + 显示模式） | 必须在 `HAL_TIM_Base_Start(&htim3)` 之后调用 |
| `lcd1602_write_lines(const char l1[16], const char l2[16])` | 写两行文字 | **定长 16 字符**：不足补空格，不能当 C 字符串 |
| `lcd1602_write_frame(l1, l2, cursor_enabled, cursor_row, cursor_column)` | 带光标控制的版本 | D6 之后可以拿它做"输入光标" |
| 宏 `LCD1602_CHAR_ANGLE`（值 1） | 自定义字符"°"的编号 | 显示角度单位时可选 |

### 1.2 ttp229 —— 30 路触摸原始读取（libttp229.a）

| 函数 | 作用 | 备注 |
|------|------|------|
| `uint32_t ttp229_read_physical(void)` | 读回 30 键位图 | bit0~bit29 = 物理键 T0~T29；GPIO 模拟两线时序（非硬件 I²C）；依赖 `htim3` |

### 1.3 touch_filter —— 触摸滤波（libtouch_filter.a）※ 你的方案不使用

| 函数 | 作用 | 备注 |
|------|------|------|
| `touch_filter_init(touch_filter_t *f)` | 初始化滤波器 | 结构体定义公开（约 36 字节） |
| `touch_filter_update(touch_filter_t *f, uint32_t raw)` | 去抖，返回 0 或单个键位 | 约定每 10ms 调一次 |

> 你的方案里被 D5 自写的去抖替代 → 按 README 规则**从 CMakeLists 链接列表删除**。

### 1.4 touch_model —— 触摸组合识别模型（libtouch_model.a）※ 你的方案不使用

| 函数 | 作用 |
|------|------|
| `touch_model_reset(m)` / `touch_model_load_default(m)` | 复位 / 载入内置默认模型 |
| `touch_model_add_sample(m, intended_key, observed)` | 追加一个训练样本 |
| `touch_model_classify(m, observed)` | 位图 → 键号推断（抗串扰） |

> 内部矩阵约 901 字节（**不能放任务栈**）。你未使用 → 同样从链接列表删除。

### 1.5 calculator_engine —— 表达式计算引擎（libcalculator_engine.a）※ 你的方案用自写替代

| 函数 | 作用 | 备注 |
|------|------|------|
| `calc_status_t calculator_evaluate(const char *expr, calc_angle_unit_t unit, uint8_t allow_complex, calc_complex_t answer, calc_complex_t *result)` | 完整表达式求值（括号/函数/复数） | 第 4 个参数 `answer` 是**按值传参**；依赖 libm |
| `calc_status_t calculator_solve_linear(float a, float b, float *x)` | 解一元一次方程 | — |

> D6 你写了 `mycalc_eval` 后 → 从链接列表删除（顺带省下 libm 约 9 KB）。
> 若 D7 选任务 5 方案 (b)，再把它加回来直接调用（提交说明里注明是库实现）。

### 1.6 calculator_app —— 示例应用（libcalculator_app.a）※ D2 起被你替换

| 函数 | 作用 |
|------|------|
| `calculator_app_init(void)` | 建队列 + 初始化（调度器启动前调用） |
| `calculator_heartbeat_task(void)` / `calculator_key_task(void)` / `calculator_controller_task(void)` / `calculator_compute_task(void)` / `calculator_lcd_task(void)` | 5 个任务体 |

> **重要理解**：`main.c` 里那 5 个任务入口函数（`StartDefaultTask` 等）调用的就是这 5 个名字。
> D2 删掉这个库、改由你的 `User/app.c` 提供**同名**实现后，**main.c 一行都不用改**——
> 链接器会自动找到"你自己的版本"。这就是 README "逐模块替换"的机制。

## 2. 工程骨架里的项目函数（读懂 / 少数要加代码）

| 函数 | 位置 | 作用 | 你要做什么 |
|------|------|------|-----------|
| `MX_USB_DEVICE_Init(void)` | usb_device.c | 初始化 USB 设备栈并启动 | D2：在 main.c USER CODE 2 里**调用**它（删掉屏蔽宏之后） |
| `CDC_Transmit_FS(Buf, Len)` | usbd_cdc_if.c（头文件已声明） | 从 USB 发数据给电脑 | D3：在 `app_usb_send` 里调用（注意 `USBD_BUSY` 要重试） |
| `CDC_Receive_FS(...)`（static） | usbd_cdc_if.c | 收到电脑数据的回调（**中断上下文**） | D3：在 `USER CODE 6` 区里**加一段拷贝循环**（骨架已给） |
| `CDC_RxTake(dst, max_len)` | usbd_cdc_if.c | **D3 你新增**：任务侧取走环形缓冲数据 | 骨架已给，照抄；同时在 .h 里加声明 |
| `CDC_RxOverflow(void)` | usbd_cdc_if.c | **D3 你新增**：查询缓冲是否溢出过 | 同上 |
| `CDC_TakeExportRequest_FS(void)` | usbd_cdc_if.c | 示例自检用的标志取走函数（本镜像无调用方） | 不用动；**当"短临界区"写法参考**读一遍 |

## 附录 A：常用"非自定义"标准 API 速查（不用背，会查就行）

| 函数 | 来源 | 用途 |
|------|------|------|
| `osDelay(ms)` | CMSIS-RTOS2（FreeRTOS） | 任务里延时（阻塞让出 CPU） |
| `HAL_Delay(ms)` | HAL | 忙等延时（只准在低优先级任务/初始化里用） |
| `HAL_GPIO_TogglePin(port, pin)` | HAL | 翻转引脚（心跳灯） |
| `__disable_irq()` / `__enable_irq()` | CMSIS | 关/开中断（配 `__get_PRIMASK()` 用） |
| `uxTaskGetStackHighWaterMark(NULL)` | FreeRTOS | 查当前任务栈剩余（实验 B） |

## 附录 B：怎么自己查"某函数在哪"

```bash
# 1) 查头文件里有哪些接口
grep -n "函数名" example/Core/Inc/*.h

# 2) 查某个库提供哪些函数（T = 代码段符号）
arm-none-eabi-nm --defined-only example/lib/liblcd1602.a

# 3) 查最终固件里有没有链接进这个函数
arm-none-eabi-nm example/build/Debug/software.elf | grep 函数名

# 4) 全工程搜调用点
grep -rn "函数名" example/Core example/USB_DEVICE example/User
```

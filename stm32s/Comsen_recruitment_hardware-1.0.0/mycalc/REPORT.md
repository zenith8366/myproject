# 光电2607班龙远航的comsen招新硬件组试题报告
## 一 完成的任务
### 核心完成内容：

1. USB通信：启用 USB CDC 虚拟串口，电脑发送文本接收并在 LCD1602 上显示成功

2. 触摸按键：自行实现按键滤波逻辑（30ms 去抖 + 单键锁定，按住只触发一次）与 30 键位映射，支持边沿判定

3. 核心计算：实现了带 AC/DEL/BACK（含8层撤销栈）的四则运算，支持连续计算与结果回填

4. 高级扩展：括号嵌套、三角函数、对数、幂运算、隐式乘法（如 2pi），并实现了复数模式、显示精度切换、SHIFT 副功能、编辑光标与 MODE 设置菜单

### 技术实现与模块替换：

1. 复现：编写并替换了 calculator_app.c、touch_filter.c和 calculator_engine.c三个核心模块

2. 保留：底层驱动（liblcd1602.a、libttp229.a）以及 FreeRTOS 与 ST USB 原来的框架作为底层保留使用

## 二 学到的东西

环境配置，硬件焊接，stm32基础知识，多任务的处理于协调，
c语言基础，计算器原理，按键去抖，AI agent的使用

## 三 遇到的困难

1. 环境和工具链难配置
2. 对项目整体运行方式难以把握，不知道每个函数变量有什么用
3. usb无法识别
4. 对各种算法的不理解，如按键滤波，环形缓冲区，递归下降求值器
5. 焊接技术太菜，ttp229芯片虚焊

之前写过或读过的代码，都只有简简单单一个文件，对于各种库也只会调用，不明白背后如何实现。

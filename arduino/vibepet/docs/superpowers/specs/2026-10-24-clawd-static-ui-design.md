# Clawd 静态画面重设计

日期：2026-10-24
状态：已与用户确认

## 背景

当前固件使用逐帧动画，占用了大量 Flash（32098/32256，仅余 158 B），且用户认为画面不够贴近
Claude 的品牌形象。用户要求：**抛弃之前所有动画设计，改为全静态画面，以 Claude 的
螃蟹吉祥物 Clawd 为核心重新设计，提高还原度**。

## 已确认的设计决策

1. **全静态**：取消所有逐帧刷新，包括审批边框闪烁、`LOST` 闪烁；只在状态切换时重绘。
2. **形象**：Claude Code 官方吉祥物 **Clawd**——珊瑚橙像素螃蟹。
3. **背景**：米白 `#FFF5E2`（Clawd 官方卡片风格），**不与 Clawd 的珊瑚橙同色**。
4. **主色**：Claude 经典橘 `#D97757`（Clawd 本体）。
5. 保留竖屏 128×160、七种状态、LED/蜂鸣器、`DONE` 3 秒回 `IDLE`、审批与交互提醒语义。

## 七态静态画面

| 状态 | 眼睛（逻辑） | 道具 | 状态色 |
|---|---|---|---|
| `IDLE` | `open` 4×4 方块 | 无 | 珊瑚橙 |
| `WORKING` | `half` 下半 4×2 | 笔记本电脑挡在身体下半：深色屏 + 青绿代码行 + 灰键盘底座 | 蓝靛 |
| `NEEDS_YOU` | `wide` 5×5 方块 | 头顶感叹号（金黄），静态 | 金黄 |
| `DONE` | `happy` 笑眼 `^ ^` | 右侧对勾 + 两个闪光点 | 青绿 |
| `ERROR` | `x` 叉眼 | 右上方乌云 + 三滴雨 | 警示红 |
| `LOST` | `closed` 横线 | 头顶断线符号（两段波纹 + 斜杠） | 灰蓝 |
| `CHECK PC` | `open` 方块 | 右上方小显示器 + 指向箭头 | 蓝紫 |

- 标题用内置 5×7 字体放大 2 倍，`INK` 深色，左侧 6×6 状态色方块。
- 正文气泡：白底、`INK` 2px 边框、圆角 6；文字 `INK`，最多 3 行，超出用 `..` 收尾。
- 审批态与交互态**不再闪烁**，用状态色细线与道具表达。

## 实现方式

- 删除 `updateAnimation()` 与 `loop()` 中的调用；删除 `animPhase`、`lastAnimMs`、
  `lastBlinkMs`、`borderOn`、`ANIM_FRAME_MS`、`BLINK_MS`、`DONE_FRAME_MS`、
  `ERROR_FRAME_MS`、`LOST_FRAME_MS`。
- 删除所有按帧参数绘制的图标函数，改为无参数的静态绘制函数。
- `renderState()` 在每次状态切换时整屏重绘：背景 → 标题 → 状态线 → 道具 → Clawd → 气泡。
- `DONE` 3 秒回 `IDLE` 保留（用 `stateSince` + `millis()`，不是动画）。
- `LOST` 检测、LED、蜂鸣器、按钮、协议全部不变。
- 正文折行沿用现有 `bodyLine()` / `drawBodyText()`，气泡内限制 3 行、宽 108 px。
- 所有绘制仍分片并 `pumpSerial()`，任意连续阻塞 ≤ 3 ms。

## 资源预算

删除逐帧动画后预计 Flash 下降；新增 Clawd 静态绘制（矩形/圆角矩形）约 300–500 B。
目标编译后 Flash ≤ 32256 B，并留出至少 300 B 余量。

## 测试与验收

- 固件编译零警告，Flash/RAM 在预算内。
- `g++` 离线测试 55/55；四套冒烟 12/14/14/9。
- 上机：七态静态画面正确、Clawd 造型与官方图标一致（宽扁身体、水平细钳、四细腿）、
  米白底与珊瑚橙对比清晰；`DONE` 3 秒回 `IDLE`；LED/蜂鸣器；审批与 `CHECK PC` 语义正常。
- 文档同步：`CLAUDE.md`、`README.md`、设计文档 v3.0 的静态画面与配色说明。

## 风险

- 米白背景在 1.77" 屏上亮度较高，长时间显示可能刺眼；若用户实机觉得刺眼，再提供深色变体。
- 128×160 高度有限，正文 3 行会截断长摘要（横屏时是 5 行）；截断用 `..` 明示。
- Flash 余量仍然紧张；若超限，优先精简装饰（状态线、闪光点），不减 Clawd 主体。

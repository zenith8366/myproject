# VibePet 中文字库字集清单
#
# 这个文件决定「设备的屏幕认得哪些汉字」。tools/gen_cn_font.py 会读它，
# 从 U8g2 的文泉驿点阵宋体里抠出这些字，生成 firmware/VibePet_UNO/cn_font.h。
#
# 规则：
#   · 井号后面的内容是注释；其余**所有非空白字符都会被收录**（顺序无所谓，自动去重排序）
#     —— 写成「已批准拒绝」或「已批准 拒绝」都行，中文不加空格也照样能读
#   · ASCII 可打印字符（0x20–0x7E）由脚本自动全量包含，不用写在这里
#   · 每多一个字，固件大约多占 20 字节 Flash。想省空间就删掉用得少的组
#   · 屏幕上出现「空心方框」= 那个字不在本清单里 —— 把它加进来重新生成即可
#
